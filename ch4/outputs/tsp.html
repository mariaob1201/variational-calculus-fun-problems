Held-Karp (Bellman sobre subconjuntos) contra vecino-más-cercano + 2-opt, sobre datos reales de ciudades de EE.UU.

Dos técnicas, el mismo principio de optimalidad

El TSP también se puede resolver con una recursión de Bellman — Held-Karp — pero la "etapa" ya no es el tiempo, sino el tamaño del subconjunto de ciudades visitadas: dp[S][j] = costo mínimo de partir de la ciudad 0, visitar exactamente el conjunto S y terminar en j. Es exacta, pero O(2ⁿ·n²) — en Python puro es práctica hasta ~15-18 ciudades. Para el conjunto completo (50 ciudades) eso es inviable (2⁵⁰ subconjuntos), así que ahí se usa una heurística: vecino más cercano + mejora local 2-opt.

Datos: las 50 ciudades más pobladas de EE.UU. (plotly/datasets, us-cities-top-1k.csv, derivado de datos censales), con distancia real sobre la esfera (fórmula de haversine).
